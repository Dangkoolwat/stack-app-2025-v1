# Roadmap

This roadmap describes the planned direction of the project.

## v0.1.x

* Stabilize the initial Spring Boot 4 and Vue 3 starter structure
* Improve README setup instructions
* Add clearer environment variable documentation
* Add example configuration files
* Add basic contribution guidelines
* Publish the first alpha release

## v0.2.x

* Improve test coverage for backend core modules
* Add more practical API examples
* Improve Docker Compose local development flow
* Add deployment notes for OCI and common cloud environments
* Improve frontend structure and sample pages

## v0.3.x

* Add more security-focused documentation
* Add CI workflow examples
* Add automated dependency review guidance
* Improve OpenAPI documentation workflow
* Add example production checklist

## Future ideas

* Korean and English documentation
* Example service module
* Admin dashboard starter
* AI-assisted maintainer workflow documentation
* Codex-based PR review and issue triage workflow
* Template-based project generation guide
