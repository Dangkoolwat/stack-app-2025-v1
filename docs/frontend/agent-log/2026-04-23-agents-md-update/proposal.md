# 해결 방안 제안

## 제안 1: 기존 Synchronization 항목 고도화 (추천)
기존의 `Synchronization` 항목을 사용자가 제공한 구체적인 명령어로 교체합니다.

- **변경 내용**: `updateGraphify` 명령어 언급을 `graphify update . && mv graphify-out/* docs/graphify/`로 구체화.
- **장점**: 에이전트가 별도의 스크립트 존재 여부를 확인하지 않고도 즉시 실행 가능한 명령어를 제공함.
- **위험 요소**: 없음.

## 제안 2: 별도의 Update 항목 추가
기존 항목은 유지하고 새로운 `Update` 항목을 추가합니다.

- **변경 내용**: 새로운 불렛 포인트 추가.
- **장점**: 기존 규칙을 보존함.
- **단점**: 중복된 지침이 발생할 수 있음.

## 선택 이유
사용자가 "관련항목이라면 명령어가 수정이 되었어요"라고 언급하였으므로, 기존의 불분명한 명령어를 새로운 구체적인 명령어로 대체하는 방안 1이 가장 적절합니다.
