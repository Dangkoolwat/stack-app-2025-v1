# 제안

## 방안 1. 공통 UI 토큰과 레이아웃만 먼저 정리

- `global.scss`에 색상, 간격, 패널, 액션, 페이지네이션 규칙을 추가
- 장점: 빠르게 전체 품질을 끌어올릴 수 있음
- 단점: 홈/내비게이션의 체감 개선은 제한적일 수 있음

## 방안 2. 공통 토큰 + 핵심 화면 동시 개선

- 전역 토큰 추가
- 상단 내비게이션 재구성
- 홈 대시보드 개편
- 게시글/사용자 목록 화면에 공통 패턴 적용

## 선택

- 방안 2 선택

## 선택 이유

- 사용자가 바로 체감할 수 있는 화면은 홈, 메뉴, 목록 화면이다.
- 전역 스타일만 바꾸는 것보다 핵심 화면에 실제로 적용해야 효과가 명확하다.
- 백엔드 API 변경 없이 프런트엔드만으로 수행 가능하다.

## 리스크

- 기존 Bootstrap/JHipster 패턴과 새 패턴이 일시적으로 혼재할 수 있다.
- 전체 lint는 기존 레포의 선행 포맷 이슈까지 포함해 여전히 실패할 수 있다.
