# 문제 분석

## 문제 현상

- 상단 내비게이션이 기술 분류 중심이라 업무 흐름을 빠르게 파악하기 어렵다.
- 로그인 후 홈 화면이 운영 대시보드 역할을 하지 못하고 환영 메시지 수준에 머문다.
- 게시글 목록, 사용자 목록 등 핵심 리스트 화면이 공통 툴바와 하단 네비게이션 규칙 없이 제각각 구성되어 있다.
- 모달 하단 액션, 폼 하단 취소/저장 버튼, 카드/패널 간격이 화면별로 일관되지 않다.

## 재현

1. 로그인 후 홈 진입
2. 게시글 목록 및 사용자 관리 화면 이동
3. 삭제 확인 모달, 하단 페이지네이션, 상단 액션 버튼 위치 비교

## 원인

- JHipster 기본 CRUD 구조 위에 부분 수정만 누적되어 공통 UI 계층이 정리되지 않음
- 글로벌 디자인 토큰과 페이지 레이아웃 규칙이 부재
- 공통 `PageHeader`, `Toolbar`, `FormActions`, `ModalActions`, `TableFooter` 패턴이 없음

## 영향

- 사용자가 화면을 탐색할 때 인지 부하가 높음
- 같은 작업이라도 화면마다 조작 감각이 달라짐
- 후속 UI 개선 시 화면별 개별 대응 비용이 커짐
