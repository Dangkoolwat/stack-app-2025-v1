# 해결 방안 제안

## 방안: 체크박스 리스트 기반의 취사선택 UI 도입 (최종 선택안)
- **UI 개선**:
    - 장식적 요소(Card, Border, Background)를 모두 제거하고 "Profiles" 레이아웃 아래 직접 권한 항목을 나열.
    - 멀티 셀렉트 대신 **체크박스 리스트**를 도입하여 클릭(취사선택)만으로 할당 가능하게 함.
    - 배지(Badge) 형태보다 정돈된 리스트 형식을 통해 가시성 확보.
- **정책 보호**:
    - 시스템 전체 권한을 수정할 수 있는 "신규 생성(Add)" 및 "삭제(Trash)" 접근 지점을 완전히 제거.
    - 기존에 정의된 `user_authority` 항목들 내에서만 선택할 수 있도록 제한함.
- **기술적 해결**:
    - `v-for`와 `d-flex flex-wrap`을 활용한 유연한 레이아웃 구성.
    - `toggleAuthority` 메서드를 통한 실시간 상태 동기화.

- 없음. 정책 준수와 사용성 향상을 동시에 달성함.
