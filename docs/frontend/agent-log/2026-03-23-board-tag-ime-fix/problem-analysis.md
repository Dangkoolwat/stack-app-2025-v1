# 문제 분석

## 현상
게시글 등록 화면의 "Tags" 입력 영역에 한글("첫태그")을 입력하고 엔터를 누르면 "첫태그", "그" 와 같이 마지막 글자가 분리되어 두 개의 태그로 등록되는 버그가 발생.

## 원인
- `bootstrap-vue-next`의 `<b-form-tags>` 등 일반적인 UI 프레임워크 컴포넌트는 내부적으로 `keydown.enter`를 수신하여 태그를 추가함.
- 한글 등 이중언어(IME) 입력 시 문자가 조합되는 중(`isComposing === true`)에 엔터를 누르면 브라우저가 조합을 완료하기 위한 `Enter` 이벤트를 발생시키는데, 해당 이벤트가 컴포넌트에 그대로 전달되어 첫 번째 태그("첫태그")를 추가하게 됨.
- 조합이 끝날 때 마지막 문자("그")에 대한 `input` 이벤트 등이 물리적으로 처리되면서 혹은 컴포넌트의 추가적인 키 처리 로직으로 인하여 두 번째 태그("그")가 중복/초과 생성되는 Chrome/Safari의 고질적인 IME 동작 버그임.

## 영향 범위
- 게시글 등록 및 수정 화면의 Tags 입력 컴포넌트 동작에 제한.
- 다른 데이터나 백엔드 로직에는 무관.
