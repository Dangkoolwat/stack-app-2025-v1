# 문제 파악

## 현상
1. 관리자 페이지의 `공통코드 상세관리` 화면에서 기본적으로 아무 그룹 코드도 선택되어 있지 않은 상태일 때, 본문 영역에 "상세 코드를 찾을 수 없습니다."라는 메시지가 노출됨. 올바른 메시지인 "공통 코드를 선택하세요."가 표시되어야 함.
2. `공통코드 상세관리`에서 그룹 코드(예: 게시판 유형)를 선택하여 해당하는 상세 코드 목록을 띄운 뒤 `추가` 화면으로 넘어가면, 작업(저장/취소) 완료 시 브라우저 기본 뒤로가기(`router.go(-1)`)가 실행됨. 이로 인해 최초 진입 경로 등에 따라 그룹 코드가 해제된 상위 페이지(또는 예상치 못한 페이지)로 돌아가버리는 문제가 발생함. 선택했던 그룹 코드 필터링이 풀리지 않은 상태로 명시적인 반환이 되도록 보장해야 함.

## 재현 경로
1. 관리자 로그인 후 `/common-code-detail` 접속
2. 안내 메시지가 "찾을 수 없습니다" 로 나오는 것 확인
3. 드롭다운에서 `BOARD_TYPE`(게시판 유형) 등을 선택 수 목록 확인
4. 목록 상단 `추가` 버튼 클릭
5. `추가` 화면 진입 후 `취소` 또는 데이터 `저장` 클릭 시 이전의 필터링 된 화면이 일관되게 복원되지 않는 경우 관찰 가능.

## 원인
1. `common-code-detail.vue` 화면의 `notFound` 조건이, 조회되는 로우(row) 데이터가 빈 배열 `[]` 인지만 체크하고 있어 '선택되지 않았을 때의 상태'를 제대로 반영하지 못하고 있음 (`selectedGroupCode` 존재 여부의 별도 alert 분기 미비).
2. `common-code-detail-update.component.ts` 에서 화면 이탈 액션(`save` 후속 처리 및 `previousState`) 로직을 `router.go(-1)`로 구현해 두어 브라우저 히스토리에 의존하고 있음. 만약 직접 링크로 타고 왔거나 새로고침 직후일 때는 뒤로가기 동작이 예상과 다르게 작동할 수 있음.

## 영향 범위
- 오직 Vue 프론트엔드의 화면 표시 및 UI 라우팅 (UX)
- 백엔드 로직, 데이터베이스, 공통 API 등에는 영향 없음. 프론트엔드 라우팅에 국한.
