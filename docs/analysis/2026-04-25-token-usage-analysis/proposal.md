# 토큰 최적화 방안 (Token Optimization Proposal)

## 1. 지침 최적화
- **AGENTS.md 슬림화**: 중복되거나 너무 상세한 설명을 요약하고, 핵심 원칙 위주로 재구성합니다.
- **분할 참조**: 모든 규칙을 하나의 파일에 넣기보다, 필요할 때만 참조할 수 있도록 `docs/standards/` 등으로 세분화합니다.

## 2. 워크플로우 효율화
- **Trivial 작업 범위 확대**: 현재 10라인 미만인 Trivial 기준을 조금 더 완화하여 불필요한 문서 생성을 줄입니다.
- **문서 통합**: 6개의 문서를 생성하는 대신, 핵심 내용(분석+계획+결과)을 하나의 문서로 통합하는 `Lightweight Log` 방식을 도입할 수 있습니다.

## 3. 스킬 관리
- **미사용 스킬 제거**: 현재 프로젝트에서 실제로 사용하지 않는 스킬(예: `bootstrap-vue3`가 이미 충분히 익숙하다면 제거 등)을 정리합니다.
- **스킬 요약**: `SKILL.md`의 내용을 핵심 API와 사용 패턴 위주로 축약합니다.

## 4. 로그 관리
- **과거 로그 아카이빙**: 특정 기간이 지난 로그는 `archive/` 폴더로 이동시켜 에이전트의 기본 검색 범위에서 제외합니다.
- **KI(Knowledge Item) 적극 활용**: 상세 로그 대신 요약된 KI를 우선 참조하도록 유도하여 컨텍스트 효율을 높입니다.

## 5. 단계별 검증 도입
- **Fast Track 활용**: 로컬 영향도가 낮은 작업에 대해서는 `Adaptive Workflow`의 `Fast Track`을 적극 활용하여 절차를 간소화합니다.
