# 문제 분석 (Problem Analysis)

## 문제 현상
- 현재 파일 업로드 정책(확장자, MIME 타입, 용량 제한 등)은 DB에서 관리되지만, 이를 빠르게 설정하기 위한 '권장 템플릿'은 프런트엔드 코드(`settings.component.ts`)에 하드코딩되어 있습니다.
- 운영자가 새로운 파일 타입(예: PSD)에 대한 정책을 추가하고 싶을 때, 매번 레이블과 확장자, MIME 타입을 수동으로 입력해야 하는 불편함이 있습니다.

## 원인
- 초기 구현 시 빠른 개발을 위해 템플릿을 정적으로 관리했으나, 요구사항이 다양해짐에 따라(PSD 등 특수 포토샵 파일 요구 등) 템플릿 자체를 동적으로 관리할 필요성이 생겼습니다.

## 영향
- 코드 수정 없이 운영자가 직접 템플릿을 등록할 수 없어 유연성이 떨어집니다.
- 프런트엔드와 백엔드 간의 정책 동기화가 수동으로 이루어져야 합니다.
