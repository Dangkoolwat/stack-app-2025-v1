# 문제 분석 (Problem Analysis)

## 현상 및 트러블
- 백엔드 서버가 구동된 직후 첫 사용자가 접속하게 되면 공통 코드(Common Codes) 등 매우 빈번하게 사용되는 데이터 세트임에도 불구하고 최초 DB 조회 지연 시간(Cold Start)이 발생함.
- 공통 코드는 어플리케이션 전반에서 드롭다운, 라벨링 등에 필수적으로 쓰이므로 이 부분을 캐싱해야 응답성을 개선할 수 있음.

## 원인
- 캐시 서버(Redis)가 초기화되거나 앱이 배포되었을 때 캐시에 공통 코드 데이터가 적재되어 있지 않은 상태에서 사용자 트래픽을 맞이하기 때문임.
