## 문제 현상
- 관리자 페이지의 Add Detail Code 페이지에서 새 상세 코드를 등록할 때 ORA-00001 (Unique Constraint Violation) 및 ORA-03301 에러가 발생하며 데이터 추가가 실패함.
- 에러 메시지에 "열 값(ID:3)이 있는 행이 존재합니다" 라는 구체적인 내용이 나타남.

## 원인
- `common_detail_sequence_generator` 시퀀스의 초기 시작값을 구성하는 Liquibase changelog 파일(`202510081910000_create_common_code_tables.xml`) 내부에서 `startValue`가 `1`로 설정되어 있음.
- 동일한 액션에서 샘플 데이터(ID 1~21)가 테이블에 초기 Insert 됨.
- 새로운 코드를 추가하기 위해 JPA(Hibernate)가 시퀀스를 호출하면, 시퀀스는 1, 2, 3 등의 번호를 순차적으로 반환함. 
- 이전에 등록된 수동 샘플 데이터 PK 목록과 해당 반환 번호가 정확히 일치하여 고유 키 충돌 오류가 발생. 즉, 사용자가 직접 인덱스 값을 삽입하려 한 것이 아니라, JPA가 채번한 값이 예전 샘플 데이터와 중복된 것임.

## 영향
- 시스템 관리자가 신규 상세 코드를 DB에 등록할 수 없는 치명적인 버그.
