# 문제 분석

## 문제 현상
- 사용자 관리 화면의 프로파일(권한) 설정 레이아웃이 기존 JHipster 기본 제공 멀티 셀렉트 박스로 되어 있어 사용성이 떨어짐.
- 관리자가 새로운 권한을 인라인으로 생성하거나 삭제하는 기능이 필요했으나, 동시에 시스템 권한 정책에 따라 임의 생성이 제한되어야 한다는 요구사항이 발생함.
- 시각적으로 테두리나 배경 등 불필요한 장식적 요소가 많아 미니멀한 구성이 필요함.

## 원인 분석
- **UX 부재**: 멀티 셀렉트 박스의 불편한 조작 방식(Ctrl/Cmd 키 조합).
- **정책 상충**: 자유로운 생성/삭제 기능이 조직의 보안 및 정책 관리 원칙(User Authority Policy)과 충실히 연동되지 않음.
- **디자인 노이즈**: 카드 레이아웃과 도움말 문구가 오히려 시각적 가독성을 저해함.

## 영향 범위
- `UserManagementService`: API 연동 메서드.
- `user-management-edit.vue`: 권한 선택 UI 전반.
- `user-management-edit.component.ts`: 권한 할당 및 상태 관리 로직.
