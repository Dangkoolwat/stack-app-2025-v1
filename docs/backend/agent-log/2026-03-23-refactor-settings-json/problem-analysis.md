# 문제 분석 (Problem Analysis)

## 문제 현상
- 현재 설정(Global Settings) 항목이 늘어남에 따라 `stack_settings` 테이블의 컬럼이 지속적으로 추가되고 있습니다.
- 이는 새로운 설정 항목을 추가할 때마다 DB 스키마 변경(Liquibase) 및 엔티티 수정이 수반되어 유지보수 오버헤드가 발생합니다.

## 원인
- 설정 항목들이 개별 컬럼으로 설계되어 있어, 구조적 유연성이 부족합니다.

## 영향
- 시스템 리부팅 없이 설정을 적용하는 기능(`GlobalSettingsService`)은 잘 작동하고 있으나, 데이터 구조의 확장성 문제가 있습니다.
- 새로운 설정 항목 추가 시 개발 생산성이 저하됩니다.
