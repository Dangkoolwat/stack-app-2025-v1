# 구현 흐름 (Walkthrough)

## 주요 구현 사항
- **동적 정책 엔진**: 운영자가 관리자 화면에서 실시간으로 업로드 허용 확장자와 MIME 타입을 제어할 수 있습니다.
- **Tika 기반 보안**: 확장자 위조를 방지하기 위해 파일의 실제 바이너리를 읽어 MIME 타입을 추출하고 정책과 대조합니다.
- **아키텍처 개선**: 도메인 엔티티가 서비스 DTO를 참조하던 문제를 VO 패턴으로 해결하여 ArchUnit 테스트를 통과했습니다.
- **관리자 UX**: `b-dropdown` 기반의 템플릿 기능을 통해 이미지, 오피스, 한글 문서 등을 클릭 한 번으로 빠르게 설정에 추가할 수 있습니다.

## 핵심 코드
- `UploadService.matchPolicy()`: 확장자 및 Tika 분석 결과를 종합하여 최적의 정책을 찾는 핵심 로직.
- `Settings.getFileTypePolicies()`: JSON 데이터를 VO 리스트로 변환하는 로직.
