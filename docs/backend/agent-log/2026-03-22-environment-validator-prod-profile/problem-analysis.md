# 문제 분석 (Problem Analysis)

## 현상 및 배경
- Spring Boot 애플리케이션의 설정 구조상, DB 접속 정보나 인증 시크릿(JWT)과 같은 핵심 환경 변수가 존재하지 않아도 서버 구동 단계가 즉시 실패하지 않고 진행되는 취약점이 있음.
- 운영(`prod`) 환경 배포 시, 필수 OS 환경 변수나 `.env` 파일 값이 누락되어 있으면 사용자가 서비스에 접속하여 기능 오류를 마주하는 시점(Lazy Fail)에야 장애를 알게 되는 위험한 상황이 발생.

## 재현 / 문제점
- `JWT_SECRET`을 세팅하지 않고 상용 모드를 실행하면 기본값에 의존하거나 런타임 NullPoint 에러를 맞음.
- DB 연결 정보(`SPRING_DATASOURCE_*`)가 누락되면 애플리케이션 프레임워크가 부트 스트랩을 시도했다가 Datasource 초기화 실패로 뒤늦게 종료되며, 그 원인 추적이 즉각적이지 않음.
