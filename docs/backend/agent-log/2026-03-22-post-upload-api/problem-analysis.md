# Problem Analysis

- 현상: 클라이언트(Vue 3) 웹 에디터(TOAST UI Editor) 및 멀티 드래그 앤 드롭 파일 첨부에서 실제 파일을 저장해 줄 백엔드 업로드 API가 부재했음.
- 원인: 기반 스토리지 객체(`UploadService`, `stack_upload_file` 테이블)는 마련되어 있었지만 프론트엔드 연동을 위한 단건 업로드 `POST` 통신부 및 사용자가 직접 파일을 삭제할 시의 보안 로깅(소프트 삭제 처리) 인터페이스가 누락됨.
- 영향 볌위: 클라이언트 단에서 마크다운에 이미지를 직접 등록할 때 서버에 연결하지 못하며, 악의적인 대용량 파일 반복 에러 공격 등을 당할 수 있음.
