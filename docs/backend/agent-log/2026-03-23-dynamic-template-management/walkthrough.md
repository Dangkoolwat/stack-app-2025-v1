# 동적 파일 업로드 정책 관리 구현 완료 보고서

정적으로 관리되던 파일 업로드 제한(확장자, MIME 타입, 용량)을 운영자가 관리자 UI에서 실시간으로 변경할 수 있는 동적 시스템으로 전환을 완료했습니다.

## 주요 변경 사항

### 1. 백엔드 (Spring Boot) - 데이터 구조 및 로직
- `Settings` 엔티티: `globalSettings` JSON 필드에 `fileUploadDefaults` 및 `fileTypePolicies` 구조를 통합했습니다.
- 동적 검증 로직: `UploadService.validateFile()`이 이제 `GlobalSettingsService`를 통해 최신 정책을 조회합니다.
    - 이중 매칭: 1차로 확장자 기반 매칭을 시도하고, 실패 시 Apache Tika를 이용해 실제 파일 콘텐츠의 MIME 타입을 분석하여 매칭되는 정책을 찾습니다.
    - 정책 적용: 매칭된 정책에 따라 허용 여부, 활성화 상태, 최대 용량을 검증합니다.
- 초기 데이터 통합: Liquibase (`20251005203000_added_entity_Settings.xml`)를 통해 이미지(표준), PDF 등 권장 기본 정책이 자동으로 로드됩니다.
- 동적 템플릿 관리 (NEW): 이전에 하드코딩되어 있던 9가지 권장 템플릿(HWP, 오디오, 비디오 등)을 DB(`fileTypeTemplates` 필드)로 이동하여 운영자가 직접 관리할 수 있도록 개선했습니다.

### 2. 프런트엔드 (Vue 3) - 사용자 경험 개선
- 템플릿 관리 UI: 설정 페이지 하단에 '파일 정책 추천 템플릿 관리' 섹션을 추가하여 템플릿의 추가, 수정, 삭제가 가능합니다.
- 동적 드롭다운: '빠른 정책 추가' 및 행별 '마법봉(템플릿 적용)' 기능이 이제 DB에 저장된 최신 템플릿 목록을 실시간으로 반영합니다.
- BootstrapVue 통합: `b-dropdown` 컴포넌트를 사용하여 UI 일관성과 안정성을 확보했습니다.

### 3. 문서화 및 실행 가이드 업데이트
- `README.md`: 최근 진행된 Jackson 3 통합, 동적 파일 업로드 정책 시스템, Apache Tika 기반 보안 강화 내용을 `Migration Highlights`에 반영했습니다.
- 실행 커맨드 명시: 로컬 백엔드 실행(`./springboot`) 및 프런트엔드 실행(`npm start`), 접속 주소(`https://localhost:9000`)를 최신 정보로 갱신했습니다.

## 검증 결과

### 자동 테스트
- `SettingsResourceIT` & `GlobalSettingsServiceT`: `SettingsDTO` 생성자 변경에 따른 테스트 코드 수정 및 통과 확인.
- 연관 테스트: `UploadServiceT`를 포함한 관련 단위 테스트 모두 Pass.

### 수동 검증
- 동적 반영: 템플릿 관리 섹션에서 새로운 확장자(예: PSD) 템플릿을 추가한 뒤, 정책 추가 드롭다운에 즉시 나타나는 것을 확인했습니다.
- 영속성: 설정 저장 시 DB에 JSON 형태로 올바르게 저장되며, 페이지 새로고침 후에도 유지됨을 확인했습니다.

### 보안 및 안정성
- 모든 파일 업로드 정책 API는 `ADMIN` 권한을 가진 사용자에게만 허용됩니다.
- 잘못된 정책 설정(용량 0 등)에 대한 유효성 검사가 포함되어 있습니다.
