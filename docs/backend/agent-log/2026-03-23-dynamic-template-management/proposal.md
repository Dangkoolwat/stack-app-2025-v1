# 핵심 구현 제안 (Proposal)

## 방안 1: 템플릿 DB 관리 및 동적 UI 제공 (선택)
- **내용**: `Settings` 엔티티의 JSON 구조에 `fileTypeTemplates` 필드를 추가하고, 이를 관리할 수 있는 전용 UI를 제공합니다.
- **장점**: 운영자가 PSD, AI 등 어떠한 포토샵/디자인 파일 템플릿도 즉시 추가하고 적용할 수 있어 가장 유연합니다.
- **선택 이유**: 사용자(운영자)의 편의성을 극대화하고, 시스템의 확장성을 확보하기 위해 가장 적합한 모델입니다.

## 방안 2: 프런트엔드 정적 템플릿 확장
- **내용**: 요청된 PSD 타입을 프런트엔드 코드에 추가합니다.
- **단점**: 향후 다른 파일 타입 요구 시 다시 개발 공수가 발생합니다.
