# 문제 분석

1. 게시글/댓글 작성 시 요청 본문의 `userId`를 그대로 신뢰하고 있었습니다.
- 인증된 사용자가 아닌 다른 사용자 ID를 넣어도 작성자로 저장될 수 있어 권한 위조가 가능했습니다.

2. private 업로드 다운로드가 "로그인 여부"만 확인하고 있었습니다.
- 소유자 또는 관리자만 접근해야 하는 파일을 다른 일반 사용자도 다운로드할 수 있었습니다.

3. 게시글 애그리거트 생명주기 처리가 delete 중심으로만 일부 구현되어 있었습니다.
- restore 시 댓글, 업로드, 태그 관계가 함께 복구되지 않았습니다.
- hard delete 시 연관 엔티티와 태그 사용량 정리가 완결되지 않았습니다.

4. 완료 보고 문서와 실제 코드 상태 사이에 차이가 있었습니다.
- 문서상으로는 정합성이 확보된 것으로 정리되어 있었지만, 실제로는 보안과 생명주기 경계가 남아 있었습니다.

5. 테스트 보강이 필요했습니다.
- 사용자 위조 요청, 타 사용자 private 파일 접근, 애그리거트 restore/hard delete 시나리오를 재현하는 통합 테스트가 부족했습니다.
