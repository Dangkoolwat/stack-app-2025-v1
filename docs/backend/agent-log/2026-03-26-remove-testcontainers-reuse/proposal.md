# 해결 방안 제안

## 선택한 방안

테스트 컨테이너 설정에서 `withReuse(true)`를 제거한다.

선택 이유

- 현재 사용자 요구사항이 "재사용을 쓰지 않는 방향"으로 명확하다.
- 재사용이 비활성화된 환경에서는 기능상 이점 없이 경고만 남긴다.
- 테스트 격리 측면에서도 기본 비재사용 동작이 더 단순하고 안전하다.

## 대안

`~/.testcontainers.properties`에 `testcontainers.reuse.enable=true`를 추가해 재사용을 활성화하는 방법도 있다.

채택하지 않은 이유

- 사용자가 재사용 자체를 원하지 않았다.
- 재사용은 속도 이점이 있지만 상태 오염 가능성과 환경 의존성이 함께 증가한다.
