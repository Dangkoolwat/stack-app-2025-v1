## 제안: 샘플 데이터에서 하드코딩된 인덱스 제거 및 시퀀스 위임 (채택)
- 방법: `202510081910000_create_common_code_tables.xml`에서 수작업으로 입력하던 `valueNumeric="1"` 형태의 하드코딩 ID를 모두 `<column name="id" valueSequenceNext="common_detail_sequence_generator"/>`로 교체합니다. 
- 초기값 정상화: 시퀀스의 `startValue`는 기존처럼 `1`로 되돌립니다.
- 이유: 사용자님의 의견처럼, 초기 데이터든 프로그램에서든 특정 인덱스를 명시할 이유가 없습니다. 데이터 입력 책임 전반을 DB의 시퀀스 혹은 Auto-Increment에 전적으로 위임하는 것이 가장 유지보수성과 확장성이 높은 클린 아키텍처 방식입니다. 이렇게 수정하면, Liquibase 기동 시 샘플 데이터들이 시퀀스 번호를 1부터 21까지 발급받아 채우게 되고, 그 직후 프로그램이 구동되면 자연스럽게 22부터 채번하므로 완벽히 동작합니다.
- 리스크: 로컬 환경을 완전히 초기화(Drop & Create)해야 깔끔히 반영됨.
