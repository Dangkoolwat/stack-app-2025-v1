# Release Note: 동적 파일 업로드 정책 및 템플릿 시스템 (2026-03-23)

사용자 편의성을 높이고 다양한 파일 타입에 대응하기 위해 관리자 설정 기능을 고도화했습니다.

## 🛠 기술적 해결 사항 (Backend)
- **DB 스키마 최적화**: `global_settings` 컬럼을 `CLOB`으로 확장하여 대용량 JSON 데이터 저장 기반을 마련했습니다. (Oracle `ORA-12899`, `ORA-22858` 오류 해결)
- **데이터 안정성 강화**: `FileTypePolicy` VO의 필드 타입을 개선하여 Jackson 3 환경에서의 JSON 매핑 안정성을 확보했습니다.
- **통합 테스트**: Oracle XE 환경에서 `SettingsResourceIT`를 통해 마이그레이션 및 API 정합성을 검증했습니다(Pass).

## ✨ UI/UX 개선 사항 (Frontend)
- **추천 템플릿 시스템**: MS Office, 한글(HWP), 이미지, 비디오 등 10여 종의 표준 정책을 원클릭으로 추가할 수 있습니다.
- **레이아웃 리팩토링**: 템플릿 관리 섹션의 버튼들을 설명 바로 아래로 배치하여 접근성을 높였습니다.
- **입력 가이드 내장**: 생소한 MIME 타입(PSD, HWPX 등)을 쉽게 입력할 수 있는 팝업 가이드를 추가했습니다.
- **표준값 복원**: 클릭 한 번으로 시스템 초기 표준 템플릿으로 초기화할 수 있는 기능을 제공합니다.
