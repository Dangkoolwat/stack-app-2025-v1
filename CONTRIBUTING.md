# Contributing

Thank you for your interest in contributing to this project.

This repository is currently maintained as a practical full-stack starter project for Spring Boot 4 and Vue 3 applications. Contributions that improve stability, documentation, developer experience, security, testing, or deployment workflows are welcome.

## How to contribute

1. Fork this repository.
2. Create a feature branch.
3. Make a focused change.
4. Run the relevant tests and checks before submitting.
5. Open a pull request with a clear description of the change.

## Contribution guidelines

Please keep pull requests small and focused.

Good contributions include:

* Documentation improvements
* Bug fixes
* Test coverage improvements
* Security-related improvements
* Docker and deployment refinements
* Spring Boot, Vue, or dependency migration fixes
* Developer experience improvements

Please avoid large, unrelated changes in a single pull request.

## AI-assisted contributions

AI-assisted contributions are welcome, but the contributor is responsible for reviewing and validating the final result.

Before submitting AI-generated or AI-assisted code, please check:

* The code matches the existing project structure.
* No unrelated files were changed.
* No secrets, credentials, or private data were added.
* The project builds successfully.
* The change is explained clearly in the pull request.

## Pull request checklist

Before opening a pull request, please confirm:

* I have tested the change locally.
* I have updated documentation if needed.
* I have kept the change focused.
* I have checked that no sensitive information is included.
* I have explained why this change is useful.

## Code of conduct

Please be respectful and constructive. This project aims to be useful for developers who want a practical and maintainable full-stack starter.
