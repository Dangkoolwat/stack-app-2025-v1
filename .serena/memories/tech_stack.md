# 💻 Tech Stack

## 🔙 Backend
- **Framework**: Spring Boot 4
- **Language**: Java 21+
- **Persistence**: JPA (Hibernate 7), Liquibase (Migration)
- **Database**: H2 (Dev), Oracle (Prod)
- **Caching**: Redis (Redisson), JCache
- **Security**: Spring Security, JWT Auth, Rate Limiting (Bucket4j)
- **Build Tool**: Maven (`./mvnw`)

## 🔜 Frontend
- **Framework**: Vue 3 (Composition API, `<script setup>`)
- **State Management**: Pinia
- **Styling**: Bootstrap Vue Next (Bootstrap 5), Bootswatch, SCSS
- **Build Tool**: Vite
- **Testing**: Vitest, Vue Test Utils
- **HTTP Client**: Axios

## 🛠️ Infrastructure & Tools
- **Containerization**: Docker Compose
- **Standardization**: JHipster-based scaffolding
- **API Documentation**: OpenAPI (Swagger)
